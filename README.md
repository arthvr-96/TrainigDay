# 🏋️ Workout Planner — Liquid Glass

Планировщик тренировок в стиле Apple Liquid Glass. Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

## Возможности

- **План по дням недели** — для каждого дня любое количество упражнений: название, подходы, повторы, вес.
  Можно менять порядок, редактировать, копировать день в другие дни.
- **Чек-лист** — отмечайте выполненные упражнения за любой день недели, листайте недели вперёд и назад.
- **Дашборд** — прогресс на сегодня, серия тренировок, повторения и подходы за неделю (с динамикой),
  график повторений за 8 недель, тепловая карта активности за 12 недель, статистика по каждому упражнению
  (сколько раз с каким весом, например: «20 раз · 5 кг, 10 раз · 8 кг»).
- **Тёмная и светлая тема** (следует системной, можно переключить вручную).
- **Данные хранятся локально** в браузере (`localStorage`); есть экспорт и импорт в JSON.
- Адаптивный интерфейс для телефона и компьютера.

## Запуск

Откройте `index.html` в браузере — этого достаточно.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки
   (**Add file → Upload files**, или через `git push`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Как считается статистика

- **Статистика по весам** — для каждого упражнения суммируются повторения (подходы × повторы) отдельно по каждому использованному весу.
- **Тренировка выполнена**, когда отмечены все упражнения дня.
- **Серия** — число подряд выполненных тренировочных дней (дни отдыха серию не прерывают).
- История хранит «снимок» упражнения на момент отметки, поэтому изменение плана не искажает прошлую статистику.
